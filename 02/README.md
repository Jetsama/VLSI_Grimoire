# Transistors, Mosfets, and the death of discrete compodents

It is often said that a transistor is a switch. This is definitely true for how tranistors are used in the digital domain.

I instead think about transistors as valves for water. In digital logic, these valves are used as on and off by opening the valve completely or closing it completely, but in analog circuits use these valves between fully open and fully closed.
