## What is an inverter?
It inverts! Okay, a better explanation would be that it returns the oposite of what is inputed.

Here is an example of how an inverter could be represented in javascript.

```javascript
function inverter(A){

    return !A
}
```

That means that:

```javascript
inverter(True)
```
and 

```javascript
inverter(False)
```
