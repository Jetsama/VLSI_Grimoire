# Introduction

The hardware we use on a daily basis have increased dramatically. Many of the features of these devices are akin to magic, mysteriously working without the need to understand the underlying mechanics behind them. Well, this book can act as a grimoire 



## Who is this book for?

This grimoire is being written for those intrested in IC design and mostly for myself as a journal as I learn more myself.


## What will be covered?

This book will mostly describe the elements of circuit design, both analog and digital, as well as going through some modern tools or approaches. 


## What do you need to start?

Hopefully not much! I plan to make the entiredy of the grimoire available using only a browser, but some of the other tools/examples may require cloning the repository.
